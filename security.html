Security & privacy

Your data stays with you.

This page explains how BasedNode handles data and access, without marketing language. It is short, because there is not much to hide: no tracking, no analytics, and no login to somebody else's dashboard.

BasedNode · CVR 43750194 Updated: November 2026
§ 01 — How it works

Your code lives in your own accounts.

That is the most important line on this page. When I build a system, the code sits in your GitHub, your cloud account and your own API accounts. I get access while we work together. When we are done, you can remove my access and the system keeps running. There is no vendor who can switch it off if we ever part ways.

01

No tracking tools

There is no Google Analytics, no Facebook Pixel, no advertising cookies and no third-party scripts reading your behaviour. The only thing stored in your browser is your language choice, and it lives in localStorage rather than a cookie.

02

Secrets stay server-side

API keys, passwords and other credentials live in environment variables or a secret manager on your server. They are never written into frontend code and never end up in a bundle someone can download from the browser.

03

No open ports

Services I set up sit behind Cloudflare Tunnels. There is no public IP, no open ports and no direct access to the server from the internet. Every request is encrypted and checked before it gets in.

04

Updates and fixes

Dependencies are watched and security updates roll out automatically. The system runs with the fixes that exist, and you always have a backup of your own database and your own files.

§ 03 — Questions

Is there something you want in writing?

If you need something handed to a supplier, a board or an accountant, I will write it as a proper document you can use. Tell me what you need.
